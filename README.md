# קוקו התוכי 🦜 · Попугай Коко · Koko the Parrot

משחק להורה וילד בגילאי 2–3. קוקו מתבלבל, והילד מתקן אותו. בעברית, ברוסית ובאנגלית.

**לשחק:** https://stasikboss.github.io/koko/

## מה יש במשחק

- **4 עולמות מאוירים:** חיות בחווה, בגדים בחדר, דברים בבית במטבח, צבעים בגן. 22 מילים, עם קולות חיות שמתאימים לכל שפה (הב הב / гав-гав / woof woof).
- **בכל משחק:** 3 סבבים (או 2 במשחק קצר), רגע שיחה אחרי כל סבב, הפסקת תנועה, "זוכרים?" בסוף, ומשימה קצרה לעשות בלי מסך.
- **התשובה מוצגת באנימציה:** הגרב עוברת מהראש לרגל, מברשת השיניים עפה מהכרטיס אל קוקו, והבננה הכחולה נצבעת בצהוב.
- **המשחק מתאים את עצמו לילד:**
  - מילים שהיה קשה איתן חוזרות במשחק הבא.
  - כשמילה כבר ידועה, מופיע כרטיס שלישי.
  - כשהילד טועה, כרטיס שגוי יוצא. אחרי שתי טעויות התשובה הנכונה זוהרת.
- **אזור ההורים** (לחיצה ארוכה על גלגל השיניים) מתחלק לארבעה חלקים:
  - **ביחד:** איך משחקים, ולמה המשחק בנוי כך.
  - **התקדמות:** זמן מסך להיום ולשבוע, ומצב כל מילה, עם התרגום בשתי השפות האחרות.
  - **קול:** בחירת קול המכשיר, והקלטת כל משפט בקול שלכם.
  - **הגדרות:** שם, שפה, אורך משחק, רמת קושי, ומספר משחקים ביום.
- **פרטיות:** בלי פרסומות, בלי קישורים החוצה ובלי איסוף מידע. הכול נשמר רק במכשיר, והמשחק עובד גם בלי אינטרנט.

## התקנה על הטלפון

- **אייפון (ספארי):** פותחים את הקישור ← כפתור השיתוף ← "הוספה למסך הבית".
- **אנדרואיד (כרום):** פותחים את הקישור ← תפריט ⋮ ← "הוספה למסך הבית".

כדי שהילד לא ייצא בטעות: באייפון "גישה מודרכת" (Guided Access), באנדרואיד "הצמדת מסך".

## הקול של קוקו

קוקו מנסה את הקולות לפי הסדר הזה:

1. **הקלטה שלכם** מאזור ההורים, לכל שפה בנפרד. השקט נחתך והעוצמה מאוזנת אוטומטית.
2. **חבילת קול מוקלטת** בתיקייה `audio/<שפה>/`, אם קיימת.
3. **קול המכשיר.** המשחק בוחר אוטומטית את הקול הכי טוב שמותקן, כלומר Enhanced, Premium או Google.

### יצירת חבילות קול (פעם אחת)

החבילות נוצרות עם Google Cloud Text-to-Speech, בחינם במסגרת המכסה החודשית. צריך פרויקט עם חיוב מופעל ו-API key שמורשה ל-Text-to-Speech.

1. Settings ← Secrets and variables ← Actions ← New repository secret. השם: `GOOGLE_TTS_API_KEY`.
2. Actions ← Koko voice ← Run workflow. בשדה השפה בוחרים `all`, והקול נשאר ריק כדי להשתמש בקולות ברירת המחדל.
3. הפעולה יוצרת את `audio/he`, `audio/ru` ו-`audio/en` ושומרת אותן במאגר. האתר מתעדכן לבד.

או מהמחשב: `python3 tools/make_audio.py --lang all`, ואפשר להוסיף `--list` כדי לראות את הקולות הזמינים.

## פיתוח

הקוד נמצא ב-`src/`:

- `content.js`: כל הטקסטים בשלוש השפות.
- `art.js`: האיורים והעולמות.
- `styles.css`: העיצוב.
- `app.js`: ההיגיון.
- `shell.html`: מבנה הדף.

```bash
python3 tools/build.py      # בונה index.html, את רשימות המשפטים לקול, וגרסת ZIP
```

אחרי כל שינוי צריך להעלות את `VERSION` ב-`sw.js`, כדי שטלפונים שכבר התקינו יתעדכנו.
