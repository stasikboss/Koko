# קוקו התוכי 🦜

משחק להורה וילד בגילאי 2–3. קוקו מתבלבל, והילד מתקן אותו.

- 3 סבבים: חיות, בגדים, דברים בבית. 9 טעויות של קוקו, כ־5 דקות.
- המשחק נגמר מעצמו, ובסוף יש משימה קצרה לעשות ביחד בלי מסך.
- בלי פרסומות, בלי קישורים החוצה ובלי איסוף מידע. השם וההקלטות נשמרים רק במכשיר.
- עובד בלי אינטרנט אחרי ההתקנה.

## מה מבוסס על מחקר

- **הילד מתקן טעויות:** פעוטות בני 19–36 חודשים מבחינים בין בדיחה לטעות, ומתקנים טעויות (Hoicka & Gattis, 2008). בגיל שנתיים הומור של תיוג שגוי ("כלב עושה מו") מצחיק במיוחד (Hoicka et al., 2021).
- **כל נגיעה היא התשובה עצמה:** בלי כוכבים, קונפטי או צלילי פרס. נגיעות שמפעילות "פרס" לא קשור פוגעות בלמידה בגיל הזה (Strouse & Ganea, 2016).
- **רק נגיעה, בלי גרירה,** ונגיעות בזמן שקוקו מדבר לא נספרות.
- **קצב איטי, עברית, טיימר גלוי (9 נוצות),** לפי המלצות משרד החינוך לגיל הרך (2026).
- **משימה מחוץ למסך בסוף:** ילדים בני 2–3 מעבירים פחות ממה שלמדו במסך אל העולם האמיתי, והמבוגר הוא הגשר.
- **להורה וילד יחד, מגיל שנתיים:** משרד הבריאות ממליץ על הימנעות ממסכים עד גיל שנתיים (ספטמבר 2026).

## העלאה ל־GitHub Pages (פעם אחת, כ־5 דקות)

1. ב־GitHub: **New repository** בשם `Koko`, ציבורי.
2. **Add file ← Upload files** וגררו את כל התוכן של התיקייה הזאת (כולל התיקיות `icons` ו־`fonts`). **Commit changes**.
3. **Settings ← Pages ← Source: Deploy from a branch ← Branch: main / (root) ← Save.**
4. אחרי דקה־שתיים המשחק יהיה בכתובת: `https://stasikboss.github.io/Koko/`

אם בחרתם שם אחר למאגר, עדכנו את הכתובת בשורה `og:image` שב־`index.html`, כדי שהתמונה תופיע כשמשתפים את הקישור.

## התקנה על הטלפון

- **אייפון (ספארי):** פותחים את הקישור ← כפתור השיתוף ← "הוספה למסך הבית".
- **אנדרואיד (כרום):** פותחים את הקישור ← תפריט ⋮ ← "הוספה למסך הבית" או "התקנת אפליקציה".

## אזור ההורים

לחיצה ארוכה (שנייה) על גלגל השיניים. שם אפשר:
- לכתוב את שם הילד (קוקו יגיד לו שלום).
- לשנות את קצב הדיבור.
- להקליט כל משפט של קוקו בקול שלכם. משפט שלא הוקלט מוקרא בקול העברי של המכשיר.

כדי שהילד לא ייצא בטעות: באייפון "גישה מודרכת" (Guided Access), באנדרואיד "הצמדת מסך".

## עדכון גרסה

אחרי כל שינוי בקבצים, שנו את `VERSION` בקובץ `sw.js` (למשל ל־`koko-v1.1`), אחרת טלפונים שכבר התקינו ימשיכו להציג את הגרסה הקודמת.
